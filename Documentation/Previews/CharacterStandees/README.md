# Ảnh kiểm tra standee giấy 0.7.1

Ảnh studio được dựng bằng Blender từ mesh `BattleStandeeLibrary` xuất bởi harness native và PNG trong `Picture/Standee` không chỉnh pixel. Có 18 standee trong ảnh tổng hợp, ba ảnh riêng để xem cạnh/chi tiết. Đây không phải ảnh chụp Unity hoặc bằng chứng shader/input/FPS trên Windows. Mặt thẻ nằm dưới đế trong game; preview cô lập phần giấy và đế để kiểm tra.

`review-manifest.json` ghi hash ảnh và nguồn code/asset. [Cách chạy và giới hạn](../../BATTLE_SPIRITS_CHARACTER_STANDEES.md).
